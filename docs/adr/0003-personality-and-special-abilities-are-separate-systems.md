# 「個性」與「特殊能力」是兩套獨立系統，不合併

研究白球のキセキ發現「性格」(對應本專案既有的「個性」)跟「特殊能力」是兩套獨立機制:性格從入部就天生固定、只能靠道具重抽,特殊能力則是後天透過訓練習得、可以同時持有多項,還受監督可教範圍限制。本專案決定跟隨這個分工:不把「個性」改造成後天習得,而是新增一套獨立的「特殊能力」系統,個別訓練卡的效果從「選屬性擲骰成長」整個改為「選能力嘗試學會」。這是刻意選擇:合併兩者能少一個新資料結構,但會讓「個性」失去它原本天生、貫穿全生涯的敘事意義,也跟研究到的參考機制脫勾;分開兩套系統的代價是 `Player` 需要新增一個特殊能力陣列欄位、個別訓練卡的整套解算邏輯要重寫、比賽引擎要新增多個能力掛鉤點。
