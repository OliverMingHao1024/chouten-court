# 《野球魂》白球模式：遊戲循環、體力管控與養成系統分析

> 研究日期：2026-08-20  
> 主要範圍：《プロ野球スピリッツ2024-2025》的「白球のキセキ」，並補充《プロ野球スピリッツ2026》官方已公開的連投與 DH 規則。  
> 用途：作為 `chouten-court` 設計高中棒球經營、球員養成、投手輪替與疲勞系統時的參考，不代表應直接複製 KONAMI 的數值或介面。

## 1. 研究結論

「白球のキセキ」不是以單一球員為中心的生涯模式，而是一個持續換血的高中棒球隊經營模擬。玩家扮演監督，透過每週練習、個別養成、比賽起用、投手輪替、設備維護與冬季招生，建立能跨世代延續的強校。

模式的核心不是單純累加能力值，而是同時管理四種時間尺度：

1. **每週**：有限成本下選擇練習與活動，平衡成長和恢復。
2. **每場／每日**：管理球員體力、投手當場耐力、連投和調子。
3. **每年**：面對大會、三年級引退、新生加入、選秀與畢業。
4. **跨年度**：累積學校評判、場地、設備、道具、招生能力與監督資產。

最值得借鑑的設計，是將「日常訓練體力」「投手單場耐力」「跨日恢復能力」「當日狀態」拆成不同資源。玩家不能只養一名王牌，也不能永遠選擇成長最高的練習；每次短期最佳化都會影響下一場比賽或下一屆球隊。

## 3. 模式定位與長期目標

玩家以高中棒球部監督身分培養球員、參加地方大會與甲子園。比賽可以只下戰術指令，也可以操作整隊或單一球員。官方確認遊玩年數沒有上限，新生入部與三年級畢業會持續循環；新生中也可能出現模仿真實職棒選手能力與姿勢的「プロ選手憧れ部員」。

來源：

- [KONAMI《プロ野球スピリッツ2024-2025》官方模式說明](https://www.konami.com/games/prospi/2024-2025/)
- [KONAMI《プロ野球スピリッツ2026》官方網站](https://www.konami.com/games/prospi/2026/jp/ja/)

長期目標不是保存同一批球星，而是打造一個能反覆完成以下循環的組織：

```text
招生 → 培養 → 起用 → 贏球 → 提升評判與資源
     → 更好的招生與環境 → 三年級離隊 → 下一代接班
```

球員是會離開的短期資產；學校評判、設施與監督累積則是跨年度資產。這使每一屆球隊既有獨立故事，又能感受到長期經營成果。

## 4. 年度循環

實機資料所整理出的主要節點如下，實際日期可能隨年度略有變化：

| 時期 | 主要內容 | 管理重點 |
|---|---|---|
| 3 月 | 畢業、職棒球員登錄與畢業禮物 | 確認畢業成果、保留長期資源 |
| 4 月 | 新生加入、年度育成方針 | 補守位、安排個別訓練、建立新陣容 |
| 春季 | 都道府縣／地區大會、春季甲子園 | 磨合陣容、累積實戰經驗 |
| 夏季 | 都道府縣大會、夏季甲子園 | 單敗淘汰、密集賽程、王牌輪替 |
| 夏季結束 | 三年級引退、新球隊成形 | 一、二年級接班，重新設定發展方向 |
| 秋季 | 都道府縣／地區／全國大會 | 驗證新陣容、爭取春季資格 |
| 10 月 | 職棒選秀 | 依比賽表現與球探評價決定職業成果 |
| 11 月至翌年 2 月 | 冬季球探與訓練 | 招募下一屆、補強場地、恢復與特訓 |

大會以單敗淘汰為主。地方賽的成績決定能否進入地區賽、神宮大會或甲子園；越早落敗，不只失去冠軍機會，也會減少比賽經驗、信賴度、球探評價與戰績資源。

- [Hakkyuu no Kiseki：主遊戲循環](https://yakyuu.hunterbaun.net/games/Prospi/Prospi20242025/Modes/HakkyuuNoKiseki/General/Main-Game-Loop/)
- [大會生命週期與淘汰規則](https://yakyuu.hunterbaun.net/games/Prospi/Prospi20242025/Modes/HakkyuuNoKiseki/Gameplay/Tournament-Bracket-Selection/)
- [模式月曆索引](https://yakyuu.hunterbaun.net/games/Prospi/Prospi20242025/Modes/HakkyuuNoKiseki/)

## 5. 每週遊戲循環

一個典型週期包含：

1. 查看球員能力、體力、調子與近期成長。
2. 為每名球員設定個別練習目標。
3. 使用土壤、設備、書籍、道具或恢復品。
4. 依近期成長與疲勞調整先發、守位與投手安排。
5. 從當週卡片列選擇練習或其他活動。
6. 若本週有比賽，選擇操作方式並完成比賽。
7. 檢視成長、事件、疲勞與比賽結果，再調整下週決策。

### 5.1 練習卡與成本

每週會出現一排練習或活動卡。玩家在監督成本內選擇，通常最多組合三項；成本越高，效果通常越大。卡片每週向左移動，最左側未使用卡片會消失，因而不能無限保留理想練習。

相同練習同時執行時可能得到較高效果。官方 FAQ 說明，當相同練習被複數執行等情況產生特殊加成時，卡片會顯示 `△`。

來源：

- [PlayStation Blog 實機試玩](https://blog.ja.playstation.com/2024/09/24/20240924-prospi-1/)
- [KONAMI：練習卡 `△` 說明](https://www.konami.com/games/prospi/2024-2025_support/faq/0/jp/ja/ps5/item?no=142)

這個設計同時製造三種選擇：

- 現在使用普通卡，還是等待組出同類加成。
- 使用高成本成長，還是保留成本處理恢復或特殊活動。
- 消耗即將到期的卡，還是放棄它以追求更高價值組合。

### 5.2 非練習活動

活動會占用練習時段，因此本質上都有機會成本。可觀察到的活動包括：

- 練習休假：恢復全隊體力。
- 勉強會：提升學力、信賴度並恢復體力。
- 紅白戰：取得實戰型成長或特殊能力機會。
- 練習賽：同時取得比賽與訓練成長，但增加疲勞。
- 行程改善：重整卡片或提高後續練習效率。
- 城鎮設施：購買設備、書籍、能力道具、恢復品或接受治療。
- 場地維護：恢復場地或器材耐久。

這使休息不是免費按鈕，而是「放棄一次可能的成長，換取未來數週的效率與比賽戰力」。

## 6. 球員養成模式

養成由四層共同決定：個人目標、全隊週課表、環境倍率與實戰起用。

### 6.1 個別練習指示

每名球員可以指定訓練方向。典型項目包括：

- 野手：對左右投手的打擊、長打、跑力、捕球、守備、傳球、肩力、守位適性。
- 投手：球速、控球、球威、變化球、球種、投手スタミナ、疲労回復。
- 共通：打擊軌跡、恢復能力、守位轉換及其他細項。

投手仍有守備和打擊能力，野手也能改練投手或轉換守位。預設的「おまかせ」會把成長分散到多個能力；精準養成需要定期檢查能力，達到階段目標後切換下一項。

實機來源：[個別訓練與主循環](https://yakyuu.hunterbaun.net/games/Prospi/Prospi20242025/Modes/HakkyuuNoKiseki/General/Main-Game-Loop/)

### 6.2 全隊練習與個人目標的疊加

從已確認介面可以推論，養成大致遵循以下結構：

```text
個人成長
≈ 當週活動基礎經驗
× 卡片成本／同類組合倍率
× 場地與設備倍率
× 行程、事件與練習效率修正
× 個別訓練分配
```

這是設計模型，不是官方公式。KONAMI 沒有公布係數，也沒有證據支持把攻略網站的經驗門檻直接當成常數。

### 6.3 場地與練習設備

場地狀況會影響練習成長；土壤和設備可提高場地等級或特定訓練效果。連續使用會讓場地退化，設備也有耐久度並可能損壞，需要工具或維護活動修復。

官方確認設備耐久度可在「資料 → 道具 → 練習設備」查看。

來源：

- [KONAMI：練習設備耐久度 FAQ](https://www.konami.com/games/prospi/2024-2025_support/faq/0/jp/ja/ps5/item?no=145)
- [場地與設備實機整理](https://yakyuu.hunterbaun.net/games/Prospi/Prospi20242025/Modes/HakkyuuNoKiseki/General/Main-Game-Loop/)

設備因此不是一次購買、永久增益，而是一條需要持續投入的資源線。

### 6.4 比賽起用也是養成

球員上場會取得實戰經驗，並影響信賴度、特殊能力與職棒球探評價。官方明確說明：

- 在比賽中起用球員，信賴度較容易提升。
- 球探評價可透過比賽活躍或道具提升。

來源：

- [KONAMI：信賴度 FAQ](https://www.konami.com/games/prospi/2024-2025_support/faq/0/jp/ja/ps5/item?no=136)
- [KONAMI：球探評價 FAQ](https://www.konami.com/games/prospi/2024-2025_support/faq/0/jp/ja/ps5/item?no=135)

因此先發名單存在「現在勝率」和「明年成熟度」的衝突：全部使用三年級主力最容易贏，但讓一年級提早在低風險局面上場，能建立下一屆核心。

## 7. 比賽操作與戰術

白球模式提供六種主要進行方式：

| 方式 | 玩家責任 |
|---|---|
| 戰術試合 | 監督視角選擇戰術卡，不直接操作打擊投球 |
| チームプレイ（ダイジェスト） | 在關鍵局面操作全隊 |
| フィールドプレイ | 選定一名球員，操作其打擊、跑壘、守備或投球 |
| 試合觀戰 | 觀看電腦比賽，可管理部分換人 |
| 自動試合 | 高速模擬，可保留換人管理 |
| 試合結果へ | 直接模擬至最終結果 |

來源：

- [KONAMI 官方模式說明](https://www.konami.com/games/prospi/2024-2025/)
- [實機模擬與介入規則](https://yakyuu.hunterbaun.net/games/Prospi/Prospi20242025/Modes/HakkyuuNoKiseki/Gameplay/Sim-Rules/)

戰術試合不是每一球都下指令，而是在滿壘、得點圈、後半局有跑者或九局決勝等高影響局面介入。這降低完整比賽的操作負擔，同時把玩家注意力集中到換投、代打、戰術與風險最高的片段。

戰術卡並非獨立於球員資料。官方說明，當球員的基礎能力或特殊能力與戰術相容時，卡片會被強化並顯示 `△`；例如拉打類戰術搭配相符的打者特性。

來源：[KONAMI：戰術卡強化 FAQ](https://www.konami.com/games/prospi/2024-2025_support/faq/0/jp/ja/pc/item?no=149)

因此球員養成方向會改變可行戰術，而不只是提高總能力。

## 8. 體力與疲勞：必須分開理解的五項狀態

白球模式中與「累」有關的數值至少應拆成以下五類：

| 狀態 | 定義 | 主要影響 |
|---|---|---|
| `体力` | 日常訓練與活動能量 | 練習、特訓、事件與疲累狀態 |
| `スタミナ上限` | 投手本身的耐力能力 | 單場可承受的投球量 |
| `當前スタミナ` | 登板後剩餘的投球能量 | 當場表現與下一場可用量 |
| `疲労回復` | 每日恢復能力 | 連戰之間恢復多少スタミナ |
| `調子／テンション` | 當日狀態與心理表現 | 比賽表現、部分訓練或特訓成功率 |

此外還有 `ケガしにくさ`，代表受傷抗性，不應與疲勞恢復混為一談。

### 8.1 日常體力

一般練習與額外比賽會累積疲勞。持續高負荷而不休息，可能觸發全隊疲累事件並降低調子。主要恢復方式包括：

- 練習休假。
- 勉強會。
- 帶恢復標記的活動。
- 便利商店、醫院等城鎮活動。
- 體力恢復道具。
- 部分冬季或社團事件。

日常體力主要控制「能否繼續高效率成長」，不是投手單場還能投幾球。

### 8.2 投手スタミナ與跨日恢復

《プロ野球スピリッツ2026》官方 FAQ 明確說明連投規則：

- 投手前一天登板時，依前一日投球數，下一場調子可能下降一至兩階。
- 比賽消耗的スタミナ會帶到翌日。
- スタミナ每天自然恢復一部分。
- `疲労回復` 等級越高，每日スタミナ恢復量越多。

來源：[KONAMI 2026：連投、調子與スタミナ FAQ](https://www.konami.com/games/2026_support/faq/0/jp/ja/ps5/item?no=266)

2024-2025 版本未公開精確門檻，但 Ver.2.0.0 更新明確調整過「投手登板後的調子與スタミナ變動」，表示跨場疲勞已是核心機制。

來源：[KONAMI Ver.2.0.0 更新說明](https://www.konami.com/games/prospi/2024-2025/update/v200)

概念上可表示為：

```text
下一場可用スタミナ
= 上場結束剩餘量
 + 間隔天數 × 每日恢復量（由疲労回復決定）
```

```text
下一場調子修正
= 前一天投球數造成的 0～2 階懲罰
```

這兩個公式只表示資料關係，不代表官方數值。

### 8.3 捕手對投手負荷的間接影響

實機資料顯示，捕手能力不只影響守備，也會影響投手的スタミナ消耗、球速與變化球表現。這讓捕手養成成為整個投手群的效率投資，而不是只提升一名野手。

實機來源：[白球模式一般技巧與球員能力整理](https://yakyuu.hunterbaun.net/games/Prospi/Prospi20242025/Modes/HakkyuuNoKiseki/General/)

KONAMI 沒有公開捕手能力對消耗量的精確公式，因此實作時應保留為可調整的輕量修正，不宜假設巨大倍率。

## 9. 投手管理產生的決策

如果王牌投完整場，短期可能提高勝率，但會同時降低下一場的スタミナ與調子。密集單敗淘汰賽因此不能只養一名王牌。

合理的隊伍結構通常需要：

- 兩至三名具先發能力的投手。
- 至少一名可負擔長局數的第二梯隊投手。
- 短局數中繼與終結者。
- 在安全領先時提早換下王牌。
- 對較弱對手使用第二或第三先發。
- 同時養成スタミナ上限與疲労回復，而不是只提高其中一項。
- 在密集大會前保留恢復活動或道具。

真正的出賽可用性可以抽象為：

```text
投手當日可用性
= 當前スタミナ比例
× 調子修正
× 傷勢修正
× 捕手／戰術修正
```

`スタミナ` 高但 `疲労回復` 低的投手適合間隔完整的先發；スタミナ較低但恢復快的投手則更適合短局數、多場次使用。這是能力分工能成立的關鍵。

## 10. 學校的跨年度成長

學校擁有獨立於個別球員的長期資產：

- 評判與評判上限。
- 場地等級與土壤品質。
- 練習器材與耐久度。
- 可用商店、醫院、球場、書店等城鎮設施。
- 戰績點數與道具庫。
- 新生球探能力與範圍。
- 監督可教授的特殊能力。

2026 官方說明，評判不是只填滿評判條；玩家還必須完成指定條件來解除下一級評判上限。

來源：[KONAMI 2026：評判變動 FAQ](https://www.konami.com/games/2026_support/faq/0/jp/ja/ps5/item?no=265)

這建立正向循環：

```text
贏球
→ 評判、戰績點數與資源增加
→ 更好的招生與設備
→ 更高養成效率
→ 更容易贏球
```

遊戲再用以下機制抑制無限膨脹：

- 三年級強制離隊。
- 單敗淘汰造成年度風險。
- 連戰與投手疲勞。
- 設備損耗及場地退化。
- 新生品質與事件仍保留隨機性。

## 11. 對 `chouten-court` 的設計建議

### 11.1 不要把所有狀態壓成一條疲勞值

建議保留至少以下欄位：

```ts
interface PlayerCondition {
  trainingEnergy: number;      // 日常訓練體力
  condition: number;           // 當日調子
  injuryResistance: number;    // 受傷抗性
}

interface PitcherCondition {
  staminaMax: number;          // 單場／滿狀態耐力
  staminaCurrent: number;      // 當前剩餘耐力
  recoveryRating: number;      // 跨日恢復速度
  pitchesPreviousDay: number;  // 前一日投球數
}
```

這可自然表達：

- 有體力訓練，但尚未從昨天的登板恢復。
- スタミナ已恢復，但連投造成調子下降。
- 單場耐力低、恢復快的牛棚型球員。
- 單場耐力高、恢復慢的傳統先發型球員。

### 11.2 疲勞應造成決策，不只是扣能力

疲勞系統至少應提供四種可選處理方式：

1. 休息：恢復最多，但失去成長時間。
2. 低強度訓練：保留少量成長並恢復部分體力。
3. 道具／設施：不失去週期，但消耗有限資源。
4. 強行出賽或加練：維持短期成果，但提高調子下降或受傷風險。

如果只有「累了就自動降低能力」，玩家沒有真正的管理選擇。

### 11.3 投球負荷應以球數和間隔日共同計算

建議把下一日狀態拆成兩段：

```text
staminaCurrent -= gamePitchCost
staminaCurrent += dailyRecovery(recoveryRating, restQuality)
condition -= shortRestPenalty(pitchesPreviousDay, daysRest)
```

初期不必模擬每種球路的醫療負荷；先以球數、投球局數、投球強度和休息天數建立可預測模型，再視需要加入傷病史與高壓局面。

### 11.4 讓比賽起用同時影響養成

替補球員上場應獲得：

- 實戰經驗。
- 與教練的信賴度。
- 關鍵局面經驗或特性進度。
- 招募／選秀可見度。

如此玩家才會在「用最強陣容確保現在勝利」和「培養下一屆」之間作出選擇。

### 11.5 建立學校層與球員層的分離

球員層每三年大量重置；學校層應緩慢累積，但可透過設備折舊和評判門檻控制膨脹。

建議分層：

```text
SchoolState
├─ reputation
├─ reputationCap
├─ groundLevel
├─ facilities
├─ equipmentDurability
├─ scoutingReach
└─ coachKnowledge

PlayerState
├─ abilities
├─ specialTraits
├─ trainingEnergy
├─ condition
├─ trust
├─ potential
└─ pitcherWorkload
```

### 11.6 先做透明模型，再加入隨機性

白球模式保留卡片、事件、新生和比賽模擬的隨機性，但玩家仍能透過設備、訓練指示、輪值與起用降低風險。

`chouten-court` 應優先確保玩家看得懂：

- 為何這名投手今天未恢復。
- 休息一天預計能恢復多少。
- 哪項練習造成體力下降。
- 為何連投讓調子下降。
- 下一場使用該投手的代價。

隨機性可以存在，但不能遮蔽因果。

## 12. 建議的最小實作順序

若要逐步引入，不必一次完成全部白球模式：

1. **投手跨場スタミナ**：比賽消耗、每日恢復、前日球數調子懲罰。
2. **多投手輪值**：先發選擇、比賽中換投、下一場可用性預覽。
3. **日常訓練體力**：訓練消耗、休息恢復、低體力效率修正。
4. **疲労回復能力**：讓不同投手形成先發／牛棚差異。
5. **起用養成**：比賽經驗與信賴度，建立主力和新人取捨。
6. **場地與設備倍率**：跨年度學校成長及器材耐久。
7. **招生與評判循環**：贏球影響下一屆生源，但保留上限解鎖條件。

前四步就能形成可感知的投手管理；後三步再建立跨年度經營深度。
