## 整體外殼(Shell)

所有「建隊之後」的畫面都套用同一個外殼,取代目前 App.tsx 直接把畫面堆疊的做法:

```
┌─────────────────────────────┐
│ 🏀 頂點高中          山田 教練│ ← 固定頂部 HUD
│ 第1年 第5週 ・ 非賽季          │
├─────────────────────────────┤
│                               │
│      (依畫面切換的內容區)      │ ← 可捲動
│                               │
├─────────────────────────────┤
│        [ 主要操作按鈕 ]        │ ← 固定底部
└─────────────────────────────┘
```

## 技術做法

- 建立共用 `Shell`/`AppLayout` 元件(頂部HUD+內容+底部操作列)
- 定義一組設計 token(顏色/間距/字級)寫成 CSS variables,球隊配色留待之後對手校名/王牌系統做出來再掛
- 屬性數值改用簡單 `<div>` 橫條(background 漸層寬度=數值%),不需要圖表函式庫
