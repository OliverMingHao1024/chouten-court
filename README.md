# 頂点コート（chouten-court）

台灣高中籃球球隊經營模擬遊戲。玩家擔任「淡水高中」教練，在訓練、休養、招生、陣容安排與正式賽之間做出取捨，目標是在有限的執教生涯內拿下 HBL 甲級總冠軍。

本專案是純前端、無後端的單機網頁遊戲，目前仍在開發與平衡調校階段。

## 核心玩法

遊戲以週為單位推進：

```text
訓練／休養／練習賽
→ 安排正式賽先發與輪替
→ 評估戰力、疲勞與受傷風險
→ 自動模擬比賽
→ 球員累積疲勞、傷勢與實戰成長
→ 招生、畢業與下一年度接班
```

玩家需要在短期戰績與長期養成之間取得平衡。持續使用最強主力能提高當下勝率，但會累積疲勞與傷病風險；讓低年級球員進入先發或輪替，則有機會取得實戰成長並為下一屆球隊做準備。

## 已完成功能

### 球隊與生涯

- 固定執教「淡水高中」，教練姓名可手動輸入或隨機產生。
- 可選填種子碼，使招生、事件與比賽亂數可以重現。
- 12 人名冊，包含位置、身高、年級、7 項屬性、個性、球風、疲勞與傷病狀態。
- 高一至高三交錯編制，每年畢業與招生，不會整隊同時換血。
- 取得 HBL 甲級總冠軍即完成生涯；長期未奪冠則由保險上限結束生涯。
- 單季總結、生涯總結、聲望曲線、畢業生後日談與可下載的戰績分享卡。

### 每週經營

- 訓練：選擇一項全隊訓練重點，每名球員各自擲骰並依骰面取得成長。
- 全隊休養：放棄當週成長，換取確定性的疲勞恢復。
- 練習賽：選擇弱、中、強三種對手，依結果取得不同幅度的成長。
- 隨機事件卡：在非賽季提供屬性、疲勞與聲望的風險選擇。
- 每名球員具有終身固定的小幅恢復差異，年級也會影響每週恢復量。

### 正式賽

- HBL 甲級五階段：資格賽、預賽、複賽、八強與四強。
- 比賽維持全自動模擬，不做逐節操作或臨場換人。
- 每場選擇 5 名先發與最多 3 名主要輪替。
- 先發、輪替與未上場球員具有不同的戰力權重、疲勞負荷與實戰成長機率。
- 進攻節奏與防守策略兩組賽前戰術。
- 賽前顯示基準勝率、球隊戰力、疲勞折損、對手級距、預估疲勞變化與傷病風險。
- 可沿用上一場陣容，或使用「最佳戰力」「低疲勞」「培養新人」建議陣容。
- 陣容位置失衡時提供警告，但不阻擋開打。
- 賽後摘要顯示出賽名單、疲勞變化、實戰成長、傷勢與有效戰力差異。

### 球員差異

- 穩健型：降低比賽表現波動。
- 天才型：提高訓練成長效率，招生時較稀有。
- 飆分型：加強投籃與三分成長，但比賽表現波動較大。
- 隊長型：擔任先發時提供一次性的全隊戰力加成。
- 抗壓型：在八強與四強提高個人有效表現。
- 玻璃體質：受傷風險較高，但高骰面訓練會取得額外成長。

### 儲存與離線使用

- 使用 `localStorage` 自動保存單一進度。
- 具備存檔格式驗證及 JSON 匯入／匯出底層能力；匯入／匯出介面目前暫時隱藏。
- 提供 PWA manifest 與 service worker，可加入裝置主畫面。

## 開發

需求：Node.js 與 npm。

```bash
npm install
npm run dev
```

常用指令：

```bash
npm test          # 執行 Vitest 測試
npm run test:watch
npm run build     # TypeScript 檢查與正式建置
npm run lint      # 執行 oxlint
npm run preview   # 預覽正式建置
```
