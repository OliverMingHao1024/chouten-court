# 頂点コート（chouten-court）

台灣高中籃球球隊經營模擬遊戲。玩家擔任「淡水高中」教練，在訓練、休養、招生、陣容安排與正式賽之間做出取捨，目標是在有限的執教生涯內拿下 HBL 甲級總冠軍。

本專案是純前端、無後端的單機網頁遊戲，目前仍在開發與平衡調校階段。

## 核心玩法

遊戲以週為單位推進：

```text
查看四週行程與下一個正式賽節點
→ 從 9 張流動卡池選擇最多 3 張訓練卡
→ 執行全隊訓練／個別特訓／練習賽／休養
→ 安排正式賽先發與輪替
→ 評估戰力、疲勞與受傷風險
→ 自動模擬比賽
→ 球員累積疲勞、傷勢與實戰成長
→ 招生、畢業與下一年度接班
```

玩家需要在短期戰績與長期養成之間取得平衡。持續使用最強主力能提高當下勝率，但會累積疲勞與傷病風險；讓低年級球員進入先發或輪替，則有機會取得實戰成長並為下一屆球隊做準備。

## 已完成功能

### 球隊與生涯

- 固定執教「淡水高中」，教練姓名可手動輸入或隨機產生。
- 開局可選起始情境：新手教練接弱校（聲望與名冊偏弱）／一般接班／老牌名校接班（聲望與名冊偏強），只影響開局當下，之後照舊依既有規則變動。
- 開局可選「長期生涯」或「三年挑戰」；三年挑戰在達到里程碑時會詢問要結束還是轉為長期生涯繼續帶下去。
- 可選填種子碼，使招生、事件與比賽亂數可以重現；週次旁固定顯示對應的真實月份（第 1 週對應九月）。
- 12 人名冊，包含位置、身高、年級、7 項屬性、個性、球風、疲勞與傷病狀態；名冊詳細畫面會顯示依傷勢／疲勞／屬性即時合成的一句「近況」。
- 高一至高三交錯編制，每年畢業與招生，不會整隊同時換血。
- 取得 HBL 甲級總冠軍即完成生涯；長期未奪冠則由保險上限結束生涯；奪冠後也可選擇不退休、直接以同一支球隊接續下一季（王朝模式）。
- 單季總結、生涯總結、聲望曲線、畢業生後日談與可下載的戰績分享卡。
- 校史：生涯結束時的教練、戰績、最佳戰績（奪冠生涯另附陣容快照）會保存到跨生涯的校史紀錄，開局畫面可回顧歷任教練的紀錄。
- 名人堂：彙整所有校史紀錄的戰績總表、歷屆奪冠隊（歷史隊）清單與畢業生後日談精華池，開局畫面「校史」旁可開啟。
- 宿敵：可在賽前把當週對手釘選為宿敵（最多 3 所），之後有機率再次對戰，並累積交手戰績與最大逆轉分差，跨屆保存。
- 永久學校資產：聲望達到門檻會永久解鎖，共 5 項——球探網（招生候選池翻倍）、影片分析室（不論聲望高低都能看到對手偵察情資）、訓練館（每週最多可選訓練卡數 +1）、恢復中心（全隊每週體力恢復量 +2）、教練專精（個別訓練可教學的特殊能力清單多 1 項）。

### 每週經營

- 四週行程帶會標示目前週次、重要事件與距離下一場正式賽的週數。
- 固定顯示 9 張流動訓練卡，每週可在訓練點數預算內選擇最多 3 張；「快速選擇」可一鍵套用依性價比排出的組合並補上子選項預設值，選完仍可再手動調整。
- 未選卡片會逐週降低成本與效果，逾期消失後由新卡補入；點數上限與每週回復量隨聲望提升。
- 全隊訓練：選定屬性後每名健康球員各自擲骰並取得實際成長；同屬性卡片可觸發連鎖加成。
- 個別訓練：選擇球員與一項特殊能力，依對應屬性決定學習成功率。
- 練習賽與全隊休養已收編進卡池，仍保留對手強度、勝負成長與疲勞恢復效果。
- 隨機事件卡：在非賽季提供屬性、疲勞與聲望的風險選擇，成功率依當週主角球員的相關屬性與個性而定（不再是全隊統一的固定機率），選擇後會先顯示結果揭曉畫面。
- 每名球員具有終身固定的小幅恢復差異，年級也會影響每週恢復量。

### 正式賽

- HBL 甲級五階段：資格賽、預賽、複賽、八強與四強。
- 比賽真的逐節模擬（四節分數累加決定輸贏，不再是單次擲骰），分差夠接近時會跳出關鍵回合決策（加速反攻／穩紮穩打／收縮防守／交給球員自由發揮），選擇會真的改變剩餘節數的模擬參數；玩家隨時可按「快速結果」跳過剩餘節數與決策。
- 每場選擇 5 名先發與最多 3 名主要輪替。
- 先發、輪替與未上場球員具有不同的戰力權重、疲勞負荷與實戰成長機率。
- 進攻節奏與防守策略兩組賽前戰術。
- 賽前顯示基準勝率、球隊戰力、疲勞折損、對手級距、預估疲勞變化與傷病風險；已釘選的宿敵學校會額外顯示交手戰績與最大逆轉分差。
- 對手風格標籤與偵察情資（風格、模糊化戰力區間、王牌弱點）；聲望達門檻前顯示「尚未偵察」。
- 已偵察時可展開完整對手名冊（姓名／位置／年級評等），純資訊用途，不影響戰力計算。
- 可沿用上一場陣容，或使用「最佳戰力」「低疲勞」「培養新人」建議陣容。
- 陣容位置失衡時提供警告，但不阻擋開打；先發五人若有位置缺席或重複，隊伍有效戰力會依問題數打折（軟性懲罰，不強制五個位置各一人）。
- 賽後摘要顯示逐節與最終比分、個人得分／籃板／助攻、出賽名單、疲勞變化、實戰成長、傷勢、有效戰力差異、最多三項主要原因與下一步建議。

### 球員差異

- 「個性」是每名球員天生固定的一項特質，會影響訓練、比賽波動、團隊加成或傷病風險。
- 穩健型：降低比賽表現波動。
- 天才型：提高訓練成長效率，招生時較稀有。
- 飆分型：加強投籃與三分成長，但比賽表現波動較大。
- 隊長型：擔任先發時提供一次性的全隊戰力加成。
- 抗壓型：在八強與四強提高個人有效表現。
- 玻璃體質：受傷風險較高，但高骰面訓練會取得額外成長。
- 「特殊能力」是獨立的後天學習系統；新球員從零開始，可同時持有多項能力。
- 目前有 13 項可學能力，會影響特定屬性權重、團隊戰力、波動、疲勞、傷病、實戰成長或每週恢復。
- 訓練卡池畫面會提示「有固定加成的個性＋人數」與「球風契合人數」，並顯示每月依名冊球風自動輪動的「本月焦點」訓練折扣。

### 儲存與離線使用

- 支援本機多存檔槽：每個存檔各自獨立，可同時經營多支球隊，可隨時切換／刪除；舊版單一存檔會自動搬進新系統。
- 存檔會保存流動卡池、訓練點數、球員特殊能力與已解鎖成就，並具備格式驗證與版本升級鏈（舊存檔可自動升級，不會被拒絕）。
- 具備 JSON 匯入／匯出底層能力；匯入／匯出介面目前暫時隱藏。
- 提供 PWA manifest 與 service worker，可加入裝置主畫面。

### 傷勢後遺症與成就

- 重傷完全康復後有機率留下永久後遺症（隨機一項屬性永久 -1），呼應真實運動傷害的長期影響。
- 成就/稱號系統：全勝賽季、零傷賽季、大逆轉、連霸八強，純紀錄性質，於生涯總結畫面彙整顯示。

## 開發

需求：Node.js 與 npm。

```bash
npm install
npm run dev
```

常用指令：

```bash
npm test          # 執行 Vitest 測試
npm run test:watch
npm run test:coverage  # 產生測試覆蓋率報告(coverage/index.html)
npm run build     # TypeScript 檢查與正式建置
npm run lint      # 執行 oxlint
npm run preview   # 預覽正式建置
```
